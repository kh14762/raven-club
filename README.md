# raven-club
A fully-featured, infrastructure agnostic runtime that can scale to the needs of 100s of physical devices. A seperate project will be created to provide a elegant, robust api powered by a k8 cluster.
Employes design patterns that make use of service lifecycle semantics to enable a large connection pool that maintains stable high throughput. Focuses on high-scale observablilty of the infrastructure.
